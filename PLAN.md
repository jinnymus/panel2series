# План проекта
Цель — независимо от конкретного стенда выгружать результаты панелей с правами Viewer и воспроизводить графики без сети.

1. Версионировать формат архива и создать синтетический стенд с известным рядом.
2. Проверить первый вертикальный срез: dashboard UID, panel ID, абсолютное окно, экспорт точек, автономный график, сверка чисел.
3. Добавить Prometheus и InfluxDB, несколько запросов, переменные и вложенные панели. Проверять метки, единицы, шаг и частичные отказы.
4. Закрепить версии Grafana 10–13 по конкретным тегам. Проверять legacy и новые модели API на реальных образах.
5. Реализовать браузерный CSV после преобразований и PNG. Протестировать YAML-профили локаторов, локальные overrides и doctor.
6. Добавить токены для CI и интерактивный SSO с MFA. Проверить OIDC, истечение сессии, права и отдельно SAML на подходящей редакции.
   OIDC с TOTP, повторное использование сессии, серверное истечение и Viewer-токены проверены на четырёх версиях. [Матрица и границы проверки](COMPATIBILITY.md). Для SAML проверена выдача утверждения Keycloak. Полная приёмка ожидает лицензированный SP. [Протокол](SAML.md).
7. Добавить сравнение ступеней и прогонов, контроль пропусков и оценку временных лагов.
   [Команда, пример и интерпретация результатов](ANALYSIS.md).
8. Предоставить HTTP API заданий и нейтральный пример отчётного потребителя.
   [HTTP API и пример отчётного потребителя](HTTP_API.md).
9. Выпускать документацию, проверенные команды quickstart, ранбук и матрицу протестированных комбинаций вместе с кодом.

   [Проверяемый quickstart](integration/quickstart.sh), [ранбук](RUNBOOK.md) и [матрица](COMPATIBILITY.md) находятся в репозитории. Для проверки YAML-профилей есть [locator doctor](BROWSER.md).

## Открытые задачи

* Провести приёмку SAML с тестовым IdP на редакции Grafana, где SAML доступен. Критерии — вход под Viewer, повторное использование сессии и отказ после истечения.
* Для публичного выпуска владельцу выбрать лицензию и целевой репозиторий. После согласования включить лицензию в поставку, проверить quickstart из чистой копии и опубликовать проверенный коммит.

Подготовка исходной поставки автоматизирована. [Проверка архива](integration/verify-source.sh) запускает тесты и Viewer-quickstart из распакованного дерева выбранного коммита и сохраняет отчёт рядом с архивом.
